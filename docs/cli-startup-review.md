# CLI 启动模式与 VPS 引导整体 review

日期：2026-10-30。范围：CLI 参数、首次启动与历史恢复、SSH 引导、终端进度、主内核节点选择、失败回退、Web 并发操作、升级重启和文档。

## 最终行为

- 无启动参数：首次仅开面板；后续恢复最后运行/停止意图及配置模式。停止记录优先；运行状态损坏时停止并提示。旧记录迁移依赖保存的节点选择及成功缓存标记。
- `--mode global|process|pool` 显式启动；进程模式必须已有有效规则。`--no-start` 保存停止状态。参数组合、重复参数、端口与空值先校验，错误不回显密码。
- VPS 只提供管理地址、SSH 端口和密码；默认 root、22/TCP、543/UDP，省略密码用运行账户的默认 SSH 密钥。高级设置留在 Web。
- 在触碰 VPS 前检查本机 TUN、OpenSSH 和代理端口；历史代理可从本地缓存恢复，部署期间继续运行。结果未知先核查，已确认失败或完成回滚可重新预检重试；成功任务及匹配的安全节点先验证复用，不重复安装。
- 终端订阅持久任务快照；远端有界阶段历史补齐快速阶段，下载进度限频，末次字节数保留。Web 显示同一任务及全局代理启用结果。不转发原始服务/SSH 日志，不将节点凭据放入进度历史。
- 节点隔离验证成功后，生成配置中的 selector 先固定为目标节点，再启动主内核、核对实际选择并经本机 SOCKS 请求验证，最后保存启动状态。

## Review 中修正的边界

- 回滚持久化失败不阻止独立尝试恢复原内核；失败与回滚失败分别报告，远端节点保留。
- Web 启动、停止、改模式、切换节点在等待配置锁前就撤销 CLI 自动启用意图。控制器切换及节点选择持久化与配置操作串行。
- 普通启动、Web 启动及配置重启恢复节点时不再派生延迟任务，避免旧选择覆盖本次 CLI 或用户最新选择。
- 本地任务目录读取失败不再视为“没有历史任务”；任务快照持久化完成后才通知终端。通知落后可重新读快照，最终快照保存失败不会无限等待。
- 内置升级重启剥离模式、停止标志、VPS 参数与密码；外部服务重复携带参数时识别历史任务。SSH 密码不写入配置、任务或日志，仍受命令行历史/进程参数可见性的限制。
- 退出时说明远端后台任务可能继续，并提供原任务标识；不把断开 SSH 描述为远端部署已取消。
