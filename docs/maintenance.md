## 网页升级

网页升级在后台运行，刷新或关闭页面不会取消升级。升级请求会实际 GET 检查下载地址，GitHub 直连请求失败或在 8 秒内未收到响应头时，自动尝试在原 URL 前加上 `https://httptunnel.top/gh/`；版本元数据、SHA256 文件和程序下载均有代理回退。下载仍必须通过大小、SHA256 和程序版本校验。升级过程与结果保存在主配置同目录的 `config.upgrade.json`（自定义配置名时使用对应文件名），弹窗会在刷新后恢复，右上角显示“升级中”。重启后只有目标版本和 sing-box 恢复检查通过才显示成功；失败结果会保留到用户关闭弹窗。

升级会重启进程，现有登录会话失效，需要重新登录。升级重启不重放一次性的模式、VPS 部署及密码参数，改为从持久状态恢复。

## 备份与迁移

停止 Miao 后备份运行账户的 `$HOME/.miao`，以及自定义主配置所在目录的配置、认证文件和需要保留的任务记录。只备份 `config.yaml` 不足以保留缓存节点、面板密码与运行状态。认证文件及节点缓存包含敏感数据，备份应限制访问。

恢复时保持相同的路径和运行账户环境，或显式指定 `--config`。`/tmp/miao-sing-box` 是运行产物，无需备份。VPS 服务位于远端，不会随本机备份迁移；恢复节点见 [VPS 部署](vps-deployment.md)。

## 常见问题

| 现象 | 检查方向 |
| --- | --- |
| 首次打开只有密码设置页面 | 设置初始密码后进入面板，这是正常流程 |
| 无参数启动后代理没有运行 | 首次默认停止，后续沿用上次状态；在网页启动或使用 `--mode` |
| 重启或升级后要求登录 | 会话保存在内存中；未重启时有效期为 7 天 |
| 订阅刷新失败但节点仍在 | 保留上次成功缓存；替换链接或恢复网络后手动刷新 |
| VPS 检查显示其他 Miao 正在部署 | 执行后最多等待锁 120 秒并重新检查；超时后待原任务结束再重试 |
| 远程节点已保存但连接验证失败 | 检查节点 UDP 端口、安全组、NAT 与 VPS 出站网络 |
