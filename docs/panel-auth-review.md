# 面板认证整体 review

日期：2026-10-30。范围：统一密码登录、CLI、认证文件、会话、CSRF、WebSocket、升级重启、前端失效清理和 VPS 令牌移除。

## 实现结果

- 网页只需要一次面板登录，右上角可改密、退出；VPS 不再配置独立令牌。
- `miao --password '密码'` 设置持久密码并启动；`miao password set [密码]` 只设置后退出，缺省密码时终端不回显输入并确认。配置路径共用同一 CLI 解析结果，避免将密码中的 `--config` 误作参数。
- 密码按要求明文存储到独立的 `.auth.json`，不混入代理配置或响应。0600、所有者/文件类型校验、O_NOFOLLOW、跨进程 flock、fsync 和原子替换覆盖并发及写入失败边界。FIFO 通过非阻塞打开并校验类型拒绝，避免阻塞服务。
- 未配置/损坏/不安全认证文件锁定管理接口，无 localhost 例外，首次网页设置密码后自动登录，初始化在跨进程锁内检查且不能覆盖已有/损坏凭据。CLI 能重置密码并修复普通文件的损坏内容；不安全文件权限须管理员先修复。
- 单一中间件保护节点、订阅、代理切换、升级、VPS、Clash 代理及 WebSocket。匿名资源白名单固定；修改请求验证 Origin 和 CSRF，会话只存服务端内存，浏览器使用 HttpOnly/SameSite Cookie。
- CLI/网页改密更新凭据版本，旧会话不能再发起管理请求；旧 WebSocket 一秒内断开。后台已接受的部署不因退出/改密而取消，重新登录继续展示。

## Review 发现并修复

1. **升级重放启动密码**：内置 exec 重启移除 `--password`/`--password=…`，包括回滚重启；保留其他参数及其值，避免网页改密被升级覆盖。外部服务每次显式带密码启动仍按约定重设密码。
2. **旧异步响应覆盖新登录**：前端认证状态使用本地版本号，忽略新登录之前发出的状态响应；过期会话的旧 401 不得注销新会话。
3. **改密/退出接口失效**：这两个接口的 401 同样触发清空敏感 UI 和返回登录页，只有匿名登录/状态请求例外。
4. **多配置 Cookie 冲突**：Cookie 名按配置路径区分，避免同域不同实例互相覆盖 Cookie。
5. **WebSocket Origin 大小写边界**：Upgrade 值按大小写不敏感识别，避免 `WebSocket` 绕过来源检查。
6. **交互终端恢复**：终端输入关闭回显并处理 Ctrl-C/Ctrl-D/退格，退出时恢复终端设置；错误输出不包含密码值。
7. **界面访问收口**：登录前不挂载管理组件，不启动后台管理请求；会话失效时卸载管理 UI、关闭其连接和轮询，清空改密字段。详情提示保持精简。

## 结论与边界

未发现未处理的阻塞问题。认证文件按要求明文保存，HTTP 按要求保留，均不提供秘密加密；有文件读取权限或可窃听 HTTP 的主体可能获得密码/会话。推荐 HTTPS 或 SSH 隧道。代理后按真实连接 IP 限速，代理用户共享限速桶。反向代理需保留外部 Host、Origin 和 Cookie。

服务重启后需重新登录；任务持久化独立保留。改密不撤销已经接受的后台操作。未在真实公网反向代理、OpenWrt 或远程 VPS 上执行部署验收；此次只验证认证功能及本地隔离连接。

## 首次网页初始化补充 review

按后续要求将 CLI 初始化提示改为网页设置初始密码。`POST /api/auth/setup` 为匿名白名单接口，但必须同源，验证密码及确认值，并在与 CLI/网页改密相同的跨进程锁内判定认证文件不存在。成功后下发与普通登录相同的会话，初始化失败不得进入面板。已有密码返回 409，损坏文件返回 503，均不能重置已有管理员。并发首次设置只有一个成功，CLI 已提前设置时初始化也被拒绝。若初始化后 CLI 紧接着改密，不会为与提交密码不匹配的凭据创建会话。

首次访问者可以设置初始管理员密码，这是网页初始化的预期行为；首次对外开放后应及时初始化，或通过 CLI 预设密码。此前“不提供匿名网页初始化”的设计已由本节替代。

补充浏览器验证：中英文 × 360/1440 宽度，确认不一致不发送设置请求、成功后自动进入、初始化前无管理请求、退出后只显示登录页，全部通过。API 为模拟响应；后端初始化及并发仲裁通过真实路由/文件锁测试验证。
