# CLI 启动模式与 VPS 引导

## 启动规则

```bash
sudo ./miao                         # 首次仅开面板；后续恢复上次状态
sudo ./miao --mode global           # 全局代理
sudo ./miao --mode process          # 进程代理：先在 Web 配好进程规则
sudo ./miao --mode pool             # 代理池：沿用 Web 中的池配置
sudo ./miao --no-start              # 仅开面板，保存停止状态
```

首次没有运行记录时不启动代理。已有 `runtime.json` 时沿用最后的运行/停止状态；Web 主动停止后，无参数重启仍停止。正常退出、系统重启及升级保留运行意图。状态损坏或不可读时保持停止，日志和面板显示原因。旧安装仅在缺少运行状态文件、同时有保存的节点选择及成功配置缓存记录时迁移为运行状态；已存在的停止记录优先。

显式 `--mode` 覆盖历史停止状态；需要有效节点。进程模式还需要有效进程规则，否则保持原状态并在终端和面板提示。模式启动成功后保存模式和运行状态。模式参数不改变面板的登录规则。

## 一条命令部署并启用全局代理

```bash
# 使用运行 Miao 的账户可访问的默认 SSH 密钥/agent
sudo ./miao --mode global --vps-host 154.202.118.100

# 自定义 SSH 端口，使用 root 密码
sudo ./miao --mode global --vps-host 154.202.118.100 \
  --vps-ssh-port 2222 --vps-password 'SSH密码'
```

支持分离参数或 `--key=value`。`--vps-host` 支持 IPv4、IPv6（不加方括号）及域名；默认 SSH 用户 root、端口 22，Hysteria2 节点地址同管理地址、端口 543/UDP。只有显式 `--mode global` 可以带 VPS 参数。`--no-start` 与模式、VPS 参数互斥。端口和密码不能脱离 VPS 地址使用。

`--password` 是面板密码，`--vps-password` 是 SSH 密码。SSH 密码不写入配置、任务历史或日志，但命令行明文可能出现在 shell 历史和进程参数中。省略 SSH 密码时不会交互提示密码，使用本机 SSH 密钥；显式空密码报错。SSH 忽略用户 SSH 配置，首次连接使用 TOFU，主机密钥变化会阻止连接。

CLI 只暴露上述最小参数。自定义节点 UDP 端口、NAT 映射地址、密钥文件和下载代理等请使用 Web 高级设置。需要本机 root/TUN、OpenSSH 客户端、远端系统依赖与网络可达；不会自动修改 SSH 配置、安全组、防火墙或 NAT。

## 实时输出与结果

终端在当前进程持续输出环境检查、依赖安装、下载字节/百分比、配置、服务检查、节点保存、连接验证及全局代理启用结果。下载限频逐行输出，重定向文件或交给 systemd 收集也能阅读，不需要打开 Web。远端保留有界的阶段历史，轮询间很快完成的阶段也会补齐，终端不直接转发可能含凭据的原始 SSH/服务日志。任务阶段来自同一份持久 VPS 任务记录；登录面板后可查看，刷新不丢失。

先验证节点，再把目标节点写为内核默认选择，启动后核对选择，并通过本机 SOCKS 入站实际请求验证。全局模式保留 Miao 原有分流规则。只有全部成功才输出“全局代理已启用”。失败时保留面板，输出失败阶段及处理建议；远程已部署不代表本机代理已启用。切换失败尝试恢复原模式、选择和运行状态，回滚失败明确提示。

相同地址和端口已有成功任务及对应安全节点时，验证并复用节点，不重复 SSH 安装。未完成/结果未知的任务先核查原任务；不会盲目重复部署。已确认失败（如预检认证失败）或已完成回滚的任务，修正问题后重跑命令可重新预检并创建新任务。Web 主动启动、停止、改模式或选择节点会取代本次 CLI 自动启用意图。

Ctrl+C/SIGTERM 退出整个 Miao；远端后台任务可能继续，终端输出任务 ID 和核查提示。下次可用相同 CLI 参数核查原任务或在 Web 恢复。首次未设面板密码时也可执行 CLI 引导；浏览器仍须设置初始密码。

内置升级重启移除一次性的模式和 VPS 参数，依靠持久状态恢复。外部 systemd 若长期保留 VPS 参数，会验证并复用已保存节点；若希望遵循 Web 保存的停止状态，应在首次引导成功后将服务命令改为无模式、无 VPS 参数启动。

### 多台 Miao 共用 VPS

另一台 Miao 指向已部署的健康节点时，会恢复同一节点，保留密码和证书，不重装或重启远程服务。各台 Miao 需要各自具备 SSH 权限，共用远程带宽和节点凭据。

并发部署时，前置检查返回“其他 Miao 正在部署”；执行任务后最多等待远程部署锁 120 秒，随后在锁内重新检查并复用已完成的节点。CLI 和网页均显示等待和复用阶段。超时返回 `host_deployment_busy_timeout`，不会接管或停止另一任务；待其完成后可重试。真实的配置变更、未知服务和端口冲突仍会阻止执行。
