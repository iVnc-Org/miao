# VPS 部署整体 review

> 访问控制已由 2026-10-30 的统一面板密码登录替代。下文保留初始实现与 HTTP 兼容修复的历史记录；当前行为见 [面板认证](panel-auth.md) 和 [认证 review](panel-auth-review.md)。

日期：2026-10-29。范围：网页入口、访问控制、SSH 凭据、远端部署事务、重连恢复、本地配置提交、旧 `vps_ip`、升级/退出协调及 CI。

## 已修复的关键边界

- 第三方或归属不明的部署不再被自动覆盖；修改过的托管配置、未知覆盖项、符号链接和不安全权限停止执行。
- 凭据不再插入 shell/YAML 文本；JSON/结构化解析保留特殊字符，SSH 临时文件创建即限制权限，异常残留可清理。
- SSH 首次信任必须能保存 known_hosts；密钥变化拒绝连接。管理地址、SSH 端口、UDP 监听及外部映射分别建模。
- 远端任务独立执行，主机锁及持久日志覆盖并发、激活、回滚；断线不误报成功，重连先核查原任务。
- 事务提交后清理失败不触发回滚，避免客户端已保存节点而远端被恢复成旧配置。
- 旧 CN-only 证书迁移为 SAN 证书，保留认证、混淆和自定义配置。客户端固定信任证书，错误证书被拒绝。
- 编辑节点保留 inline certificate；相同凭据的旧 insecure 节点可升级信任且保留标签及带宽配置，不制造重复节点。不同凭据或严格 TLS 信任冲突不静默覆盖。
- 重复提交返回原任务；关闭弹窗不取消也不反复强制打开，刷新恢复活动任务。Miao 重启后重新认证核查，不保存 SSH 凭据。
- SSH 网络阶段不持配置锁；提交使用最新配置。`vps_ip` 共享部署引擎，保留运行意图，尊重部署期间手动停止。
- VPS API 仅对真实 localhost 连接免令牌；远程/反向代理支持 HTTP/HTTPS，要求令牌及同源校验，忽略转发头中的身份声明，任务响应禁止缓存。
- 部署与升级互斥；退出后不接受新部署或再提交启动核心。依赖只安装缺失项，不因缺少 PyYAML 就显式升级已有 OpenSSL。

- Rust：266 项通过，包括此前 ignored 的私有订阅语法验收及回环测试。未连接订阅中的真实服务器。
- 前端：40 项通过；ESLint、生产构建通过。
- Python：18 项通过，部署路径/系统命令全部在临时目录模拟；包含真实 sing-box 回环 Gecko 转发及错误证书拒绝。
- 浏览器：中文/英文 × 360/768/1440 三种宽度，检查、提交、幂等键、下载进度、关闭和刷新恢复通过；仅模拟 API，无浏览器异常，无横向溢出。
- `cargo clippy --all-targets` 通过；保留未使用模型、已有配置函数参数数量等现存告警。
- CI 增加远端脚本隔离测试和基于声明构建 tags 的真实主机核心回环验收。

## 验证边界

本次没有连接或修改真实 VPS。发行版包管理器和服务管理器以隔离替身覆盖，不能据此宣称真实 systemd/OpenRC、amd64/arm64 全矩阵已验收。真实 Hysteria2 v2.12.1 release 与客户端互通仍需在有授权的隔离 VPS 上验收；当前真实协议测试使用 sing-box 作为回环两端。

首次 SSH 连接仍采用 TOFU，无法替代预共享指纹的身份验证。断电/SIGKILL 依靠重连后的事务恢复，不能承诺当场回滚。软件包及新增系统账户不撤销；依赖源和 UDP 网络策略仍由运行环境决定。遇到归属不明的既有服务，应手动导入节点，不提供自动强制覆盖入口。

## HTTP 远程访问修复 review（2026-10-29）

- 取消前端和后端对远程 HTTP 的强制拦截；HTTP/HTTPS、服务器 IP/域名、IPv6 与反向代理共用令牌鉴权。监听地址保持原有配置。
- 仅真实回环连接且 Host 为回环地址、无转发头时免令牌；所有敏感接口逐次校验，不能用前端访问状态替代后端授权。伪造转发头、跨站来源、Origin/Host 或端口不匹配均不能获得免鉴权权限。
- `/api/vps/access` 只提供三个访问状态，不泄露令牌、任务或密钥路径，并禁止缓存。读取访问状态也进行来源校验。
- 令牌输入移到弹窗主区域，活动任务期间仍能更新。缺少服务端配置、无效令牌、来源错误均有可操作的提示；已有密钥说明实际读取位置。HTTP 提示明文传输，不增加确认步骤。
- Review 补充修复：修改令牌立即清空旧授权和任务；旧轮询响应不得恢复旧任务；访问状态检查后若任务接口返回 403，同样清除任务和授权。单纯断网保留进度以便恢复。
- 验证：Rust 266 通过、3 项按原设置忽略；前端 47 通过，ESLint 和生产构建通过。真实浏览器中英文 × 360/768/1440 宽度，HTTP 地址、令牌填写、预检、提交、关闭及刷新恢复通过，无横向溢出或浏览器异常。API 使用模拟响应，没有连接或修改真实 VPS。
- 结论：本次 review 未发现未处理的阻塞问题。HTTP 不提供传输加密，令牌及提交的 SSH 凭据可被网络中间人截获；这是本次兼容策略的明确边界，建议 HTTPS 或 SSH 隧道。外部反向代理与真实 VPS 网络环境仍须按实际配置验收。
